Este repositório contém a interface central de comunicação e curadoria digital de **Alexia Melusine**. Desenvolvido com foco em **Experiência Mobile First**, o portal utiliza uma arquitetura de microsserviços visuais para conectar a audiência aos canais diretos, produções audiovisuais e repositórios de código.

---

## 🌒 Estética & Tecnologias
O projeto foi concebido sob a diretriz de **Direção de Arte Visceral**, unindo tecnologia de ponta com o arquétipo do feminino proibido.

- **Design:** Bento Grid & Glassmorphism.
- **Segurança:** Ofuscação de dados sensíveis (WhatsApp/Telegram) via Base64 para proteção contra *web scraping*.
- **Interatividade:** Haptic Feedback (vibração tátil) integrado para navegação mobile.
- **Fundo Dinâmico:** Degradê Abissal (Black-to-Purple) com textura de interferência visual (efeito chuva).

## 🛠️ Como Utilizar
1.  **Hospedagem:** O arquivo `index.html` está otimizado para **GitHub Pages**.
2.  **Customização:** Os dados de contato estão codificados no `script` final para evitar spam.
3.  **Responsividade:** Layout testado para dispositivos iOS e Android, garantindo que os botões retráteis (Accordions) mantenham a fluidez.
